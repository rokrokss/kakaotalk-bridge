            Installation
            
    
              
    Prepare a Korean tablet, then install KakaoTalk through Aurora using anonymous sign-in.
    
              
              
              
    In Aurora, search for KakaoTalk by Kakao Corp. Allow app installation when Android asks. Keep “Use with other devices” selected before signing in.
    
              
              
    Install from APK files instead
    Run ./bridge import-apks /path/to/apk-folder on the server, then set up collection components. Include the base APK and all matching splits. Publisher signatures are verified.
    
              
    Existing enrollment and collection approval are preserved. These actions do not sign in for you.
    
            
    
          
    
          
    
            Passkeys and recovery
            
    
              
    Add a backup passkey on another device or security key so you can still sign in if you lose this one.
    
              
              
              
    Adding or removing a passkey asks you to confirm with an existing one. Removing a passkey signs out admin browsers and disconnects MCP clients.
