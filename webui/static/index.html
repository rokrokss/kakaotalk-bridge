어디에서 메시지를 사용하시겠어요?

AI 없이도 수집은 계속되며, 새 방식을 추가해도 기존 연결은 유지됩니다. 터미널에서는 kakaotalk-bridge setup-connection을 사용할 수 있습니다.

  1. OpenAI 터널 설정 ↗에서 터널을 만들고 ChatGPT 워크스페이스에 연결하세요.
  2. 터널 ID와 Tunnels Read + Use 권한의 실행용 API 키를 붙여 넣으세요.

터널을 만들거나 찾을 수 없나요?

터널을 만들려면 Tunnels Read + Manage, 고르려면 Read + Use 권한과 ChatGPT 워크스페이스 접근 권한이 필요합니다. 메뉴가 보이지 않으면 조직 또는 워크스페이스 관리자에게 문의하세요. OpenAI 터널 안내 ↗

리버스 프록시가 이미 이 서버로 연결되어 있어야 합니다. /mcp까지 붙여 넣어도 됩니다.

연결 방식이 보이지 않거나 승인이 끝나지 않나요?
ChatGPT 워크스페이스 권한을 확인하세요. 터널이 보이지 않으면 워크스페이스 연결과 Read + Use 권한을 확인하세요. OAuth 요청이 만료되면 AI 서비스에서 다시 연결하고 새 코드를 승인하세요. ChatGPT 연결 안내 ↗

                

              

            

          

          

            대화 이벤트
            

              
연결된 AI에 새 메시지 이벤트를 보낼 대화를 선택하세요. 기본값은 모든 대화에서 꺼짐입니다. 메시지 수집과 검색에는 영향을 주지 않습니다.

              
켜면 그 시점부터 새로 수집된 메시지의 이벤트를 허용합니다. AI 클라이언트에서도 MCP 이벤트를 구독해야 합니다. 끄면 대기 중인 이벤트가 취소되지만 이미 전송 중인 이벤트는 전달될 수 있습니다.

            설치
            

              
한국어 태블릿을 준비한 뒤 Aurora에 익명으로 로그인해 카카오톡을 설치하세요.

              
              
              
Aurora의 시작 안내와 익명 로그인을 마친 뒤 다시 열면 Kakao Corp.의 카카오톡 페이지가 열립니다. 로그인 전에 ‘다른 기기와 함께 사용’을 선택하세요.

              
              
APK 파일로 설치하기
서버에서 kakaotalk-bridge import-apks /path/to/apk-folder를 실행한 뒤 수집 구성 요소를 설치하세요. 기본 APK와 일치하는 모든 분할 APK를 포함해야 합니다. 배포자 서명도 검증합니다.

              
기존 기기 등록과 수집 승인은 유지됩니다. 이 작업으로 자동 로그인되지는 않습니다.

            

          

          

            패스키 및 복구
            

              
기기를 잃어버려도 로그인할 수 있도록 다른 기기나 보안 키에 백업 패스키를 추가하세요.

              
              
              
패스키를 추가하거나 삭제할 때 기존 패스키로 인증해야 합니다. 패스키를 삭제하면 관리 브라우저에서 로그아웃되고 MCP 클라이언트 연결도 해제됩니다.
