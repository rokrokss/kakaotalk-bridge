카카오톡 연결하기

    서버와 태블릿 확인 중…

    기기는 자동으로 준비됩니다. 아래 화면에서 스토어를 통해 앱을 설치하고 카카오톡에 로그인하세요.

    아래 태블릿에 카카오톡 설치

    1. 스토어 열기를 누르세요. Aurora의 시작 안내와 약관을 확인하고 계속하세요. 설치 방식을 물으면 Session Installer를 선택하세요.
    2. Android에서 Aurora의 앱 설치 권한을 요청하면 설정에서 이 출처 허용을 켜세요. 태블릿의 뒤로 버튼으로 Aurora에 돌아오세요.
    3. 익명(Anonymous) 로그인을 선택하세요. 카카오톡 또는 KakaoTalk을 검색하고 Kakao Corp.의 앱을 선택하세요.
    4. 설치(Install)를 선택하고 Android 설치 확인 창이 나타나면 승인하세요. 다운로드가 끝날 때까지 관리 화면을 열어 두세요.
    5. Bridge가 설치된 앱을 감지해 준비를 마칩니다. 안내가 로그인으로 바뀌고 카카오톡이 열리면 계속하세요.

    스토어에서 검색하려면 태블릿의 검색란을 누르고 화면 키보드로 KakaoTalk을 입력하세요. Bridge의 텍스트 입력은 수집 구성 요소가 준비된 뒤 사용할 수 있습니다.

    스토어 로그인이나 다운로드가 멈췄나요?

    Aurora의 오류 내용을 확인하고 익명 로그인이나 다운로드를 다시 시도하세요. 설치가 끝났는데 안내가 바뀌지 않으면 위의 다시 확인을 누르세요. 준비 중 오류가 발생했다면 준비 다시 시도를 누르세요.

    Aurora 문제 해결 ↗

    휴대폰 로그인 상태는 직접 확인해야 합니다. 태블릿 설정만으로 휴대폰 로그인이 유지된다고 보장할 수 없습니다.

    AI 연결

    ChatGPT에 아래 MCP 주소를 추가하고 OAuth를 선택하세요. 연결 중인 브라우저에서 패스키로 인증하고 접근 권한을 확인하세요.

    공개 AI 연결이 설정되지 않았습니다.

    연결만으로 이벤트가 자동 구독되지는 않습니다.

    연결 설정

    필요할 때 연결하세요

    AI를 연결하지 않아도 메시지 수집과 관리 화면을 사용할 수 있습니다.

    OpenAI에서 터널 정보 가져오기

    1. OpenAI 터널 설정 ↗에서 터널을 만들고 사용할 ChatGPT 워크스페이스에 연결하세요.
    2. 터널 ID를 복사하고 Tunnels Read + Use 권한이 있는 실행용 API 키를 발급받으세요.
    3. 이 화면으로 돌아와 두 항목을 입력하고 접근 허용 내용을 확인한 뒤 터널 설정 및 허용을 누르세요. 아래 연결 안내에 따라 마무리하세요.
    터널을 만들거나 찾을 수 없나요?

    터널 생성에는 Tunnels Read + Manage 권한이 필요합니다. 터널 선택에는 Read + Use 권한과 ChatGPT 워크스페이스의 접근 권한이 필요합니다. 메뉴가 보이지 않으면 조직 또는 워크스페이스 관리자에게 문의하세요. OpenAI 터널 안내 ↗

    서버에 저장됩니다. 저장한 키는 이 화면에 다시 표시되지 않습니다.

    본인만 접근할 수 있는 터널을 사용하세요. 대화 이벤트는 별도로 켜기 전까지 꺼져 있습니다.

    이미 Bridge에 연결된 HTTPS 주소가 있을 때 사용하세요. /mcp를 포함한 전체 URL도 입력할 수 있습니다. OAuth를 설정하며 현재 관리 화면 주소는 유지됩니다.

    Tailscale로 HTTPS 주소 설정

    필요하면 Tailscale을 설치한 뒤 Funnel과 OAuth를 설정합니다. 로그인이나 Funnel 승인이 필요하면 여기에 링크가 표시됩니다.

    1. 아래 동의 항목을 확인하고 Tailscale 및 OAuth 설정을 누르세요.
    2. 승인이 필요합니다가 표시되면 Tailscale 승인 링크를 열어 로그인 또는 승인을 완료하세요.
    3. 이 화면으로 돌아와 설정 계속을 누르세요. 추가 승인이 있으면 완료한 뒤 연결 안내에 저장된 MCP URL을 사용하세요.

    AI 클라이언트에 설정 복사

    공개 주소, OAuth, 터널이 필요하지 않습니다. 클라이언트가 Bridge를 설치한 컴퓨터에서 명령을 실행할 수 있어야 합니다.

    Bridge를 설치한 컴퓨터의 SSH 호스트 별칭이나 user@host를 입력하세요. 해당 계정은 추가 입력 없이 Bridge 설정과 Docker에 접근해 실행할 수 있어야 합니다.

    
                    
      
                      
    1. 클라이언트 설정 복사를 누른 뒤 AI 앱의 MCP 서버 설정이나 설정 파일을 여세요.
      2. 
                      
    2. 기존 서버 설정을 유지하면서 mcpServers에 kakaotalk 항목을 추가하세요. 입력 폼을 사용하는 앱이라면 표시된 명령어와 인수를 해당 항목에 복사하세요.
      3. 
                      
    3. 저장한 뒤 AI 앱의 MCP 연결을 새로고침하거나 앱을 다시 실행하세요. KakaoTalk Bridge를 활성화하고 수집 상태 확인을 요청하세요.
      4. 
                    
    
                    
    명령을 실행할 수 없으면 AI 앱에서 설치 경로에 접근할 수 있는지 확인하세요. SSH는 비밀번호 입력 없이 접속할 수 있어야 합니다.

    연결 방식이 보이지 않거나 승인이 끝나지 않았나요?
    ChatGPT 워크스페이스 권한을 확인하세요. 터널이 보이지 않으면 워크스페이스 연결 여부와 Read + Use 권한을 확인하세요. OAuth 요청이 만료되면 AI 클라이언트에서 다시 연결하고 새로 표시된 코드와 일치하는 요청을 승인하세요. ChatGPT 연결 안내 ↗
    
            
    연결 확인: AI에 수집 상태 확인을 요청하세요. 휴대폰에서 ‘Bridge 확인 14:32’처럼 구별하기 쉬운 메시지를 나에게 보내고 AI에 해당 문구를 찾아 달라고 요청하세요.
    
            
    서버 설정과 접근 승인만으로 AI 요청의 성공 여부를 알 수는 없습니다. 요청 후 현황의 원격 AI 사용 기록을 확인하세요.

            설치
            
    
              
    한국어 태블릿을 준비한 뒤 Aurora에 익명으로 로그인해 카카오톡을 설치하세요.
    
              
              
              
    Aurora에서 Kakao Corp.의 카카오톡을 검색하세요. Android에서 요청하면 앱 설치를 허용하세요. 로그인 전에 ‘다른 기기와 함께 사용’을 선택하세요.
    
              
              
    APK 파일로 설치하기
    서버에서 ./bridge import-apks /path/to/apk-folder를 실행한 뒤 수집 구성 요소를 설치하세요. 기본 APK와 일치하는 모든 분할 APK를 포함해야 합니다. 배포자 서명도 검증합니다.
    
              
    기존 기기 등록과 수집 승인은 유지됩니다. 이 작업으로 자동 로그인되지는 않습니다.
    
            
    
          
    
          
    
            패스키 및 복구
            
    
              
    기기를 잃어버려도 로그인할 수 있도록 다른 기기나 보안 키에 백업 패스키를 추가하세요.
    
              
              
              
    패스키를 추가하거나 삭제할 때 기존 패스키로 인증해야 합니다. 패스키를 삭제하면 관리 브라우저에서 로그아웃되고 MCP 클라이언트 연결도 해제됩니다.
